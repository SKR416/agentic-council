# 推薦選項選單

步驟 0 詢問使用者時可提供的中性推薦選項。格式見 `schemas/run_files.md`。

使用規則：
- 推薦選項從下列條目選用，原文照用，不得改寫成帶評價或傾向的說法。
- 「目標」類問題不使用本選單的固定條目，推薦選項只能由使用者說過的詞組合而成（見 P1）。
- 使用者採用的選項寫進簡報時，須標註「（使用者採用預設）」。

- P1 目標類問題的選項只能重新組合使用者已說過的詞句，不得加入使用者沒提過的新概念。
- P2 衡量權重選項：以長期上限為主要考量。
- P3 衡量權重選項：以短期速度為主要考量。
- P4 衡量權重選項：以成本最低為主要考量。
- P5 衡量權重選項：以穩定不中斷為主要考量。
- P6 風險底線選項：不設可承受損失的具體上限，由使用者之後補充。
- P7 風險底線選項：由使用者以金額或比例自行填入可承受的最大損失。
- P8 資源與約束選項：由使用者自行填入預算上限與完成期限。
- P9 資源與約束選項：預算與期限皆未設定，簡報中標註「未提供」。
